# Krpytos vigenere cypher

---

After watching [this excellent video](https://www.youtube.com/watch?v=jVpsLMCIB0Y) by [LEMMiNO](https://www.youtube.com/@LEMMiNO) I was inspired to try and write my own vigenere cypher system similar to the one actually used in the Krypros sculpture.

It's a pretty basic script that loads in a cypher alphabet along with a cypher keyword and then applies these to a user's inputted text to generate the encrypted message.

## Usage

1. Clone the repository
2. Create a virtual environement with `python -m venv venv`
3. Activate the virtual environment with `source venv/bin/activate` or `venv\Scripts\activate` on Windows
4. Run the script with `python main.py`
